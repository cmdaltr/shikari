## Customization

To generate reports with your own data:

```python
from archer.reports.generator import WordReportGenerator

# Your data
detections = [
    {
        "technique": "Your Technique Name",
        "technique_id": "T1234.567",
        "tactic": "Your Tactic",
        # ... more fields
    }
]

# Generate
generator = WordReportGenerator()
report_bytes = generator.generate(
    group_name="Your Group",
    detections=detections
)

# Save
with open("my_report.docx", "wb") as f:
    f.write(report_bytes)
```

See `docs/reports/REPORT_GENERATION_COMPLETE.md` for complete API documentation.

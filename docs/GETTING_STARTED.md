# Archer Setup & Support Guide

Quick reference for getting Archer configured and running.

## Prerequisites

- **Python 3.11+** (tested with 3.11-3.13)
- **Git** (for cloning the repository)

## Quick Setup (5 Steps)

### 1. Clone the Repository

```bash
git clone https://github.com/cmdshiftd/archer.git
cd archer
```

### 2. Create Virtual Environment

```bash
# Create virtual environment
python3 -m venv .venv

# Activate it
source .venv/bin/activate  # On macOS/Linux
# OR
.venv\Scripts\activate     # On Windows
```

**Tip**: You'll see `(.venv)` in your terminal prompt when activated.

### 3. Install Dependencies

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

**Note**: This installs ~150 packages. Takes 2-3 minutes.

### 4. Verify Installation

```bash
# Test CLI
python3 archer.py --help

# Test imports
python3 -c "from archer.genai import build_correlation_queries; print('✅ Success')"
```

### 5. Run the Application

Choose one:

**Option A: Web Interface**
```bash
uvicorn archer.app:app --reload
# Open browser to http://localhost:8000
```

**Option B: Command Line**
```bash
python3 archer.py --help
```

**Option C: Docker**
```bash
docker-compose up --build
# Open browser to http://localhost:8000
```

### 6. Create Admin User (First Time Only)

**Required for first-time setup** - Create your admin account:

```bash
# In a new terminal (while the app is running)
source .venv/bin/activate
python3 scripts/create_admin.py
```

You'll be prompted for:
- **Email address** - Your admin email
- **Full name** - Display name
- **Password** - Secure password (min 12 chars, uppercase, lowercase, number, special char)

> **Note**: The database (`data/archer.db`) is automatically created when you first start the application. This step only creates your admin user account.

## Common Commands

### Virtual Environment

```bash
# Activate
source .venv/bin/activate

# Deactivate
deactivate

# Delete and recreate (if corrupted)
rm -rf .venv
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### Running Archer

```bash
# Web application (with auto-reload)
uvicorn archer.app:app --reload

# Web application (production mode)
uvicorn archer.app:app --host 0.0.0.0 --port 8000

# CLI - Generate detections for threat group
python3 archer.py generate "APT29"

# CLI - Correlate detections
python3 archer.py correlate

# CLI - Hunt for specific technique
python3 archer.py hunt "PowerShell"
```

### Docker

```bash
# Start services
docker-compose up

# Start in background
docker-compose up -d

# Rebuild after code changes
docker-compose up --build

# Stop services
docker-compose down

# View logs
docker-compose logs -f archer

# Enter container shell
docker-compose exec archer /bin/bash
```

**Note**: The Docker configuration uses `GENAI_MODE=semantic` by default for intelligent correlation generation. To change this, edit the `environment` section in [docker-compose.yml](../docker-compose.yml).

### Development

```bash
# Run tests
pytest

# Type checking
mypy archer tests

# Code formatting (if installed)
black archer/
isort archer/

# Check for syntax errors
python3 -m py_compile archer/**/*.py
```

### Output Directories

Each CLI command writes its output to a dedicated directory under `data/`:

- **`data/generate/`** - YAML detection files generated by the `generate` command
  - Example: `python3 archer.py generate "APT29"` → `data/generate/APT29_detections.yaml`

- **`data/correlate/`** - JSON correlation files created by the `correlate` command
  - Example: `python3 archer.py correlate` → `data/correlate/correlation_*.json`

- **`data/hunt/`** - YAML hunt queries generated by the `hunt` command
  - Example: `python3 archer.py hunt "PowerShell"` → `data/hunt/T1059_001_hunt.yaml`

**Note**: These directories contain sample files for reference. Generated output files are excluded from git commits (see `.gitignore`).

## Troubleshooting

### Import Errors: "No module named 'bs4'"

**Problem**: Missing beautifulsoup4 package

**Solution**:
```bash
# Ensure you're in virtual environment
source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Verify bs4 is installed
python3 -c "import bs4; print('✅ bs4 installed')"
```

### "Command not found: python3"

**Problem**: Python not installed or not in PATH

**Solution**:
```bash
# macOS
brew install python3

# Linux (Ubuntu/Debian)
sudo apt-get update
sudo apt-get install python3 python3-pip python3-venv

# Verify
python3 --version
```

### Port Already in Use (8000)

**Problem**: Another service using port 8000

**Solution**:
```bash
# Use different port
uvicorn archer.app:app --port 8080

# Or kill existing process
lsof -ti:8000 | xargs kill -9  # macOS/Linux
```

### Docker Build Fails

**Problem**: Docker can't find files or build context issues

**Solution**:
```bash
# Ensure you're in project root
cd /path/to/archer

# Clean docker cache
docker-compose down
docker system prune -a

# Rebuild
docker-compose up --build
```

### Virtual Environment Won't Activate

**Problem**: Shell doesn't recognize activation script

**Solution**:
```bash
# Try absolute path
source /full/path/to/archer/.venv/bin/activate

# Or use Python directly
/full/path/to/archer/.venv/bin/python3 archer.py --help

# Or recreate venv
rm -rf .venv
python3 -m venv .venv
source .venv/bin/activate
```

### Tests Fail to Import Modules

**Problem**: Tests can't find archer module

**Solution**:
```bash
# Install package in development mode
pip install -e .

# Or run pytest from project root
cd /path/to/archer
pytest
```

## Configuration

### Advanced Options

**Web UI**: Advanced correlation options are available via checkboxes on the main page:
- **Advanced Query Parsing** - Structured query parsing for better combinations
- **Semantic Analysis** (Recommended) - Categorizes queries by purpose
- **AI-Powered Correlations** - Uses OpenAI API (requires `OPENAI_API_KEY`)
- **Local LLM Processing** - Uses local model (requires `LLAMA_MODEL_PATH`)

**CLI**: Set environment variables before running commands:
```bash
# Semantic mode (recommended)
export GENAI_MODE=semantic
python3 archer.py correlate

# AI-powered mode (requires API key)
export OPENAI_API_KEY=sk-...
export GENAI_MODE=ai_generators
python3 archer.py correlate

# Local LLM mode (requires model)
export LLAMA_MODEL_PATH=/path/to/model.gguf
export GENAI_MODE=local_llm
python3 archer.py correlate
```

### Environment Variables

Optional environment variables:

```bash
# OpenAI API Key (for AI-powered correlations)
export OPENAI_API_KEY=sk-...

# Local LLM Path (for local LLM processing)
export LLAMA_MODEL_PATH=/path/to/model.gguf

# Draft retention (days)
export DRAFT_MAX_AGE_DAYS=30
```

#### GENAI_MODE Options Explained

**`heuristic` (Default)** - Basic correlation generation
- ✅ Fast, no dependencies
- ✅ Works out of the box
- ⚠️ Simple tag-based grouping
- **Use when**: Getting started, basic needs

**`advanced_parsing` (Recommended)** - Structured query parsing
- ✅ Understands query structure (tables, fields, operators)
- ✅ Better query combination
- ✅ No extra dependencies needed
- **Use when**: Want smarter correlations without complexity

**`semantic` (BEST)** - Semantic query understanding
- ✅ All benefits of advanced_parsing
- ✅ Categorizes queries (authentication, network, file activity, etc.)
- ✅ Groups by meaning, not just tags
- ✅ No extra dependencies needed
- **Use when**: Want the smartest correlations (recommended)

**`ai_generators`** - AI-powered generation
- ⚠️ Requires OpenAI API key or other AI service
- ⚠️ Costs money (API calls)
- ✅ Most intelligent correlations
- **Use when**: You have AI credits and want maximum intelligence

**`local_llm`** - Local LLM models
- ⚠️ Requires llama.cpp or transformers
- ⚠️ Requires downloading models (~4GB+)
- ⚠️ Slower processing
- ✅ No API costs, private
- **Use when**: You want AI without cloud services

**Example: Using semantic mode**
```bash
# Activate semantic analysis for better correlations
export GENAI_MODE=semantic
python3 archer.py correlate --verbose
```

**Add to your shell profile** (optional):
```bash
# Add to ~/.bashrc or ~/.zshrc
echo 'export GENAI_MODE=heuristic' >> ~/.zshrc
source ~/.zshrc
```

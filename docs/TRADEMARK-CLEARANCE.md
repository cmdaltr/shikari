## Filing shortlist (for the attorney)

**Primary:**
- **UK (UKIPO)** — classes **9** + **42**. Home jurisdiction, cleanest register.
- **EU (EUIPO)** — classes **9** + **42**. Clear the *Shikaria Sociedad* (cl. 9) citation first.
- **US (USPTO)** — classes **9** + **42**, intent-to-use (§1(b)). Register is open.

**Consider:**
- **Class 35** if the product sells/arranges third-party goods or offers a marketplace/analytics-as-a-service angle.
- **WIPO Madrid** international application (UK or EU as base) if filing in ≥3 offices — usually cheaper than separate national filings.

**Class wording to brief:**
- **Cl. 9** — downloadable security / threat-detection software; downloadable software for generating and testing SIEM detection rules; recorded software.
- **Cl. 42** — SaaS featuring software for cybersecurity threat detection and detection-rule generation; PaaS; design and development of computer software; cybersecurity research and consultancy.

**Points to raise with the attorney:**
1. Full availability opinion incl. unregistered / common-law rights and company names (e.g. dormant UK "Shikari Limited", 05800986).
2. Closer read of EU **Shikaria Sociedad** (cl. 9) — confirm goods and conflict likelihood before the EUIPO filing.
3. Word mark vs. combined (logo) mark — recommend word mark first for widest protection.
4. "Shikari" is a dictionary word ("hunter") — confirm no descriptiveness issue for the goods (there isn't an obvious one for security software).

# Quick Notion Import Reference

Fast reference for importing Archer documentation to Notion.

---

## 🚀 Quick Start (3 Steps)

### 1. Open Notion
- Go to your Notion workspace
- Create a new page: "Archer Documentation"

### 2. Import Files
- Click "..." menu on the page
- Select "Import" → "Markdown & CSV"
- Navigate to: `/Users/ben/Library/CloudStorage/OneDrive-Personal/Projects/GitHub/archer/docs/`
- Select ALL `*_NOTION.md` files (21 files total)
- Click "Import"

### 3. Organize
- Drag and drop pages into category structure (see below)
- Add icons and covers as desired
- Done!

## 🔧 Quick Fixes

### Emoji Not Showing
- Click page icon area (top left)
- Add emoji manually from picker

### Code Block Missing Language
- Select code block
- Click "..." → Choose language

### Table Alignment Off
- Click table → Adjust column widths
- Use Notion's table formatting

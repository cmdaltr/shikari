Detections as code

Where Detections as code commits. A local repository path, and optionally a git remote to push to after each commit. Credentials aren't stored — a push uses this host's own git auth (SSH key, credential helper, or a token in the URL).

SIEM data sources

Which data sources this estate actually ingests. A detection that needs a source you don't collect can't fire — it's shown on Results with a Source not ingested badge and left out of the detections-as-code export and SIEM push. Tick only what you ingest; leave a SIEM untouched to gate nothing (everything counts as ingested). Field names are vendor-fixed, so this is availability only.

SIEM field mapping

Per-environment index, sourcetype and field names used when queries are generated. This matters for Splunk (index/sourcetype/field names vary by deployment) and Elastic (index patterns, non-ECS overrides). MDE columns and SecOps UDM paths are vendor-fixed, so overriding those is rarely needed. Saving an override replaces the base schema; Reset restores it. Changing a mapping affects newly generated queries — regenerate affected runs to apply it.

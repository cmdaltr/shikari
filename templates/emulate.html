How Emulate works

Recordings are real attacks run in a lab with logging on — the public datasets that ship with Archer, plus any you record yourself in Lab below. Each is mapped to ATT&CK, then Archer checks whether the indicators your detections match actually appear in the recorded events. The result is the Telemetry views, organised by technique, group or data source. No AI is involved.

Recorded telemetry

    Each recording is one tool run in a lab with logging on (Sysmon, Windows auditing, PowerShell, cloud audit logs), mapped to ATT&CK by the people who recorded it. It shows that a technique can be recorded and by which log, for that tool in that lab; not every way the technique can be done. The recordings ship with Archer; Update (or python -m archer.telemetry --build) fetches what the sources have changed since.

Recorded telemetry

    Each recording is one tool run in a lab with logging on (Sysmon, Windows auditing, PowerShell, cloud audit logs), mapped to ATT&CK by the people who recorded it. It shows that a technique can be recorded and by which log, for that tool in that lab; not every way the technique can be done. The recordings ship with Archer; Update (or python -m archer.telemetry --build) fetches what the sources have changed since. No AI is involved.

⚙️ OSINT API Keys (Optional)

Enhanced profiling uses multiple OSINT sources. Most work without API keys, but for full coverage set these environment variables:

  • SHODAN_API_KEY - Internet-facing assets (get free key at shodan.io)
  • SECURITYTRAILS_API_KEY - DNS history (get key at securitytrails.com)
  • GITHUB_TOKEN - Secret scanning (create at github.com/settings/tokens)
  • OPENAI_API_KEY - AI enhancement (get key at openai.com)

💡 How to set: Add to .env file in project root or export as shell variables:
export SHODAN_API_KEY="your_key_here"

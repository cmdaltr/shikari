Agents

Models that use Archer's tools step by step to repair queries, answer questions and triage reports

An agent is a model in a loop with tools. You give it a task; it decides which tool to call, reads the result, and decides again, until it has an answer. Each agent here is the same loop with different instructions and a different set of Archer's tools. The trace shows every step. Anything that changes something, such as a hunt or a saved query, waits for you to allow it unless you turn approval off.

{% if providers %} Claude is the most reliable at multi-step tool use; small local models often stop early or call tools wrongly. {% else %} Agents need a model that can call tools: add an API key or a local endpoint in Profile → API Keys.{% endif %} The same tools are available to any MCP client (archer-mcp) and in the console (agent/*).
